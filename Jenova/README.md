# Hoarbound Jenova runtime

This directory vendors the Jenova runtime and SDK needed to load and build the
project's `frost_window.cpp` script without downloading Jenova separately.

- Runtime source revision: `63ecdcb385fbcd8a59e1ed5896a6c03e0d0aacb2`
- Godot API: generated by Hoarbound's Godot 4.8-dev6 executable
- Windows: `Jenova.Runtime.Win64.dll` (build with
  `tools/ci/bootstrap_jenova_windows.ps1`)
- Linux: `Jenova.Runtime.Linux64.so` (build with
  `tools/ci/bootstrap_jenova_linux.sh`)

Both bootstrap scripts use the same pinned Jenova source and the local engine's
GDExtension API dump. The Windows bootstrap requires the Windows build toolchain
used by Jenova's MSVC builder and checks the editor scan for the missing-loader
error before reporting success.
