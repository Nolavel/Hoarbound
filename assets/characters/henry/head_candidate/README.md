# Generated Henry head candidate

`generated_head_candidate.glb` is the standalone head candidate made from the
author's portrait reference. It is shared for art and technical review; it has
not replaced Henry's current head in the player scene and is not rigged or
approved as a production character asset.

The original reference and four Blender 5.2 review renders are in
`docs/asset_previews/henry_head_candidate/`. The GLB has one textured mesh.
Check likeness, eye geometry, topology, scale, and skinning before any game
integration.
