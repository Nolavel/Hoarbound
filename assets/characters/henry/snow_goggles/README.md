# Snow goggles — optics fit candidate

`source/snow_goggles_optics_candidate.blend` contains only the owner's snow goggles. The imported GLB meshes remain unchanged in the hidden `Source_Original` collection. The visible `Glasses_Fitted` collection holds the candidate, grouped under `Goggles_Fitted_Root`.

The source has a front optical panel tilted away from the seating frame. The candidate rotates that panel toward the frame, uniformly reduces it by 8%, and removes four isolated scan chips at the sides. The frame, gasket, buckle, and strap retain their source geometry. The viewport colors are diagnostic Workbench colors, not finished materials.

This is a Blender-only geometry review. There is no Henry head, hat, game export, or Godot integration in this candidate. Review renders are in `docs/asset_previews/henry_snow_goggles/`.
